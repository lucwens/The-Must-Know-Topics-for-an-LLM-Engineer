1 · Tokenization (Byte-Pair Encoding)

DistilGPT-2 uses the GPT-2 BPE vocabulary (50,257 tokens). Common words become a single token; rare words get split into subword pieces. Leading spaces are part of the token, which is why the same word can have two IDs.

2 · Embeddings

Each token id indexes into a learned matrix of shape (vocab_size, 768). Tokens with related meanings tend to land near each other in that 768-dim space. We can see this by computing cosine similarities and by projecting the vectors down to 2-D with PCA.

3 · Positional Encoding

Attention is permutation-invariant on its own, so we have to inject position. The original Transformer paper used a fixed pattern: for every position pos and dimension i, set PE(pos, 2i) = sin(pos / 10000^(2i/d)) and PE(pos, 2i+1) = cos(pos / 10000^(2i/d)). Wiggle the sliders to see how the bands stretch and compress.

RoPE — rotary positional embeddings

RoPE doesn't add anything to embeddings — it rotates consecutive 2-D slices of each Q / K vector by an angle that depends on position. Enter any even-dimensional vector and watch each slice rotate as the position increases.

4 · The Attention Mechanism

This is the one the article highlights: every token is projected into a query, a key, and a value vector. The model decides how much one token attends to another by comparing its query to that token's key.     Each row is a query token; each column a key token. Bigger = stronger raw compatibility.

  4. Step 4 — apply the causal mask & softmax

    Because DistilGPT-2 is decoder-only, future positions are masked to −∞ before softmax — that's why the upper triangle is dark.

  5. Step 5 — output = attention · V

    Each token's new representation is a weighted sum of the value vectors, with the attention row above as the weights.

5 · Decoding Strategies

Once the model has produced logits for the next token, the decoder chooses one. Temperature reshapes the distribution; top-k truncates to a fixed number of candidates; top-p (nucleus) truncates to the smallest set whose cumulative probability passes p.

6 · Architecture Families

The same attention building block is wired up differently depending on the task. The diagram below is a real DAG — each node corresponds to a piece of the transformer stack described in the article.

Encoder-only

BERT-style. Every token sees every other token (bidirectional). Trained with masked language modeling. Strong for classification & retrieval.

[tok₁ tok₂ tok₃ tok₄]
        ↓
   bidirectional
      attention
        ↓
   contextual reps

Decoder-only (this app)

GPT-style. Each token attends only to past tokens (causal mask). Trained to predict the next token. Strong for generation.

prompt → [tok₁ tok₂ tok₃ ?]
              ↓
        causal attention
              ↓
        next-token logits

Encoder–Decoder

T5 / BART. Encoder sees the full input; decoder generates autoregressively while pulling from the encoder via cross-attention.

input → encoder ─┐
                 ▼
       cross-attention
                 ▲
output ← decoder ┘
